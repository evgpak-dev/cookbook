# Асинхронный опрос в консоли

ES-модуль на Node.js для организации последовательных асинхронных опросов в консоли.

При создании CLI-инструментов часто требуется последовательно запросить у пользователя несколько параметров.

**Пример использования**

```js
import { runSurvey } from "./survey.mjs";

async function main() {
  console.log("--- Начало опроса ---\n");

  const myQuestions = [
    "Как вас зовут?",
    "Из какого вы города?",
    "Ваш любимый язык программирования?",
  ];

  const results = await runSurvey(myQuestions);

  console.log("\n--- Опрос завершен! ---");
  console.log("Полученные данные:", results);
}

main();
```
