## Проверка сложности пароля (Политика безопасности)

В Битриксе правила сложности паролей привязаны к группам пользователей (вкладка «Безопасность» в настройках группы).

```php
<?php
use Bitrix\Main\Loader;

Loader::includeModule('main');

$password = 'MyP@ssw0rd123';
$user = new \CUser();

// Группа "Зарегистрированные" ID = 3
// Группа "Админы" ID = 1
// Для группы "Неавторизованных пользователей" нужно передать пустой массив []

$policy = \CUser::GetGroupPolicy([3]);

// Метод возвращает массив ошибок. Если массив пустой — пароль идеален!
$errors = $user->CheckPasswordAgainstPolicy($password, $policy);

if (empty($errors)) {
    echo "Пароль надежный и соответствует всем политикам!";
} else {
    echo "Пароль не прошел проверку:<br>";
    foreach ($errors as $error) {
        echo "— " . $error . "<br>";
    }
}
```
